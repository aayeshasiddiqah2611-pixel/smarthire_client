# 🤖 SmartHire – AI Resume Analyzer

🔗 Live Demo: https://agent-69cf743dc52dd17a54--thriving-khapse-eb7c72.netlify.app

SmartHire is an AI-powered web application that analyzes resumes and provides intelligent insights to help users improve their chances of getting hired. It compares resumes with job descriptions and gives actionable suggestions.

---

## 🚀 Features

* 📄 Upload and analyze resumes (PDF/DOCX)
* 🤖 AI-powered resume evaluation
* 📊 Resume scoring system (0–100)
* 🎯 Job description matching
* 🧠 Skill detection & missing skills analysis
* 💡 Personalized improvement suggestions
* ⚡ Fast UI with Vite + React
* 📱 Fully responsive design
